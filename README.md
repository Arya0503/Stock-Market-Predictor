## 🎯 Overview

This repository contains an end-to-end Time-Series Machine Learning pipeline designed to predict whether the **SPDR S&P 500 ETF Trust (SPY)** will close strictly higher (`Up`) or lower/flat (`Down/Flat`) the following day. 

Instead of chasing inflated, unrealistic accuracy metrics, this project focuses on **strict temporal integrity, zero data leakage, and rigorous baseline comparisons**.

## 🛠️ The Approach

### 1. 🛡️ Zero Leakage Target Construction
The target is constructed strictly as `1 if close.shift(-1) > close else 0`. A specific leakage verification check is printed in the notebook to confirm that the `target` column precisely maps to the comparison between the current day's close and the *next* day's close, ensuring absolutely **no forward-looking data** contaminates the current row's features.

### 2. 📊 Feature Engineering
We compare two distinct feature sets:
* **Raw Features:** OHLCV data straight from Yahoo Finance, plus a simple 1-day lagged return.
* **Engineered Features:** Utilizing the `ta` library, we compute the **Relative Strength Index (RSI)**, **MACD**, and **20-day rolling volatility**. All `NaN` values from the warmup period are rigorously dropped before splitting to preserve temporal integrity.

### 3. ⏳ Chronological Split
To accurately simulate real-world trading, the data is split chronologically into **~80% training** and **~20% test** segments. Data is **never shuffled**. A `StandardScaler` is fitted *only* on the training set and then applied to transform both sets.

### 4. 📉 Baselines for Honest Comparison
We evaluate our ML models against two naive baselines:
* **Persistence:** Predicts that tomorrow's direction will exactly match today's realized direction.
* **Majority Class:** Always predicts the dominant class label observed in the training split.

## 🏆 Results

We tested these models on a robust **31-year dataset (1993-2024)** encompassing 7,954 trading days. 

| Model | Accuracy | Precision | Recall | F1 Score |
|:---|---:|---:|---:|---:|
| 🔄 **Persistence Baseline** | `50.69%` | `55.12%` | `55.05%` | `55.08%` |
| 📈 **Majority Class Baseline** | `54.92%` | `54.92%` | `100.0%` | `70.90%` |
| 🧱 **Raw Features Model** | `54.92%` | `54.96%` | `99.31%` | `70.76%` |
| 🧠 **Engineered Features Model** | **`56.18%`** | **`56.03%`** | `93.90%` | **`70.18%`** |

## 🔍 Honest Interpretation

* 📊 **Performance vs Baselines:** The Engineered Features Model achieved a **56.1% accuracy** on the test set, successfully beating both the Majority Class (54.9%) and Persistence (50.6%) baselines. The Raw Features Model (54.9%) essentially gave up and acted as a majority-class predictor (indicated by its 99% recall), failing to extract meaningful signal.
* 🎲 **Signal vs. Noise:** With an expanded test set of roughly 1,590 trading days (~20% of 7,954 total days), the ~1.2% absolute outperformance over the majority class equates to around **19 extra correct predictions** over a multi-year window. While mathematically superior, this edge is exceedingly thin.
* ⚖️ **Class Balance & Baseline Difficulty:** The overall target distribution remains imbalanced (**~54% Up, 46% Down/Flat**) over the 31-year history. This structural market bias solidifies the Majority Class as an inherently difficult baseline to beat for major stock indices.

## 🛑 Real-World Limitations

* 💸 **No Transaction Costs or Slippage:** This model assumes execution at exactly the closing price. In reality, trading at the close or opening bell incurs slippage, and brokerage fees would rapidly eat into any potential profit margin generated by a 1.2% edge.
* 🕒 **Not Real-Time:** The model runs on end-of-day data, meaning predictions are generated for the next day, precluding any intraday opportunities.
* 📉 **Market Efficiency:** Financial markets are highly efficient. Any marginal edge discovered using simple technical indicators is often already arbitraged away by institutional players. Achieving a >50% accuracy on paper does not guarantee a profitable trading strategy.
